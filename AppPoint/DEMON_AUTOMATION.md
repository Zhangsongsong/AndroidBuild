# 封魔之地自动流程（可配置版）

## 范围

面向《正中靶心》的手动确认流程：游戏首页 → 挑战 → 封魔之地入口 → 自动战斗 → 三选一技能 → 继续战斗 → 胜利结算确认 → 返回入口。达到配置轮数后停止，不再次进场。

当前尚未完成真机验收。已提供用户录像的布局预设，可以加载入口、选卡、结算等模板及坐标；其他布局需自行校准。技能卡使用本地 ML Kit 中文 OCR，并按配置的名称优先级选卡；支持飓风流及自定义顺序。三张名称均稳定识别但无优先级匹配时随机选一张；空白或不稳定识别不触发兜底。

自动识别需要 Android 11+，使用无障碍截图 API，在设备本地比较图片，不上传截图。原有手动点击/滑动仍可使用 Android 7+；Android 6 不支持手势注入。

## 录像布局快速配置

游戏应用配置页点击“加载你提供录像的布局与模板”，加载 2026-11-16 用户录像的 544×1200 纵向布局、模板、名称 OCR 区域及点击位置，运行次数设为一轮。先打开游戏“挑战”tab，使封魔之地卡片可见，再从悬浮窗开始。预设不包含从其他页切到挑战 tab，也不包含失败/次数不足模板。屏幕比例不符时停止要求校准。

视频时刻、测量位置及验证边界见 [VIDEO_CALIBRATION.md](VIDEO_CALIBRATION.md)。先用“只识别技能（不点击）”核对名称，再试跑一轮。

## 在界面配置优先级并保存 JSON

1. 进入游戏对应的应用配置页 → 封魔之地自动流程。首次可应用飓风流预设，填入飓风、龙卷风、冰霜新星三系技能。
2. 点击“调整技能优先级列表”：上方显示已选技能及编号，点击一行后用下方工具栏“上移 / 下移 / 置顶”排序，也可编辑名称或别名；每行可移除。下方按飓风系、龙卷风系、冰霜新星系分组展示双列技能卡，点击未选卡会追加到优先级末尾，再次点击已选卡则移除，高亮卡片同步显示优先级编号。两块区域独立滚动，新加入或移动的技能会在上方滚动到可见位置。自定义技能单独分组，可移除后重新加入。顺序可以跨技能系调整，运行时不会强制恢复默认流派顺序。
3. 点击列表内“保存到本地 JSON”，立即保存技能列表、当前流派及兜底策略。取消会放弃列表内的调整。主界面的“保存技能配置到 JSON”也可保存这三项；仅修改技能设置不会覆盖坐标、模板规则、运行次数或超时。
4. 保存文件位于应用私有目录 `files/demon/<游戏包名>/flow.json`。界面显示真实绝对路径，并提供“查看已保存 JSON”和“重新加载 JSON”。每个游戏包名独立保存。
5. 显示“有未保存的技能配置”时，运行使用上一次保存的版本。保存后原会话失效，需点击悬浮窗“开始封魔 / 重新开始”，从文件重新加载；“继续”只恢复当前会话，不偷偷更新正在执行的规则。
6. 再次加载录像布局会保留已有非空技能列表、流派及兜底设置；只有主动“应用飓风流预设”才会在编辑界面重置排序，仍需保存才生效。

`flow.json` 中与技能有关的字段示例（完整文件还包括截图及流程配置，勿用此片段覆盖完整文件）：

```json
{
  "skillPriority": ["乱流", "多重飓风", "飓风增幅", "学习龙卷风|解锁龙卷风|龙卷风"],
  "skillBuild": "hurricane",
  "skillFallback": "RANDOM"
}
```

数组顺序就是优先级，`|` 分隔同一项的识别别名。保存前检查名称为空、过短及跨条目重复别名等问题；使用原子文件写入并回读校验，失败不直接覆盖有效配置。

测试：编辑、移动、重复名称拒绝、按已保存顺序选卡、保留校准参数及加载录像布局不重置优先级由本地单测覆盖；设备测试另覆盖 JSON 磁盘往返和旧字段兼容，当前仅编译，尚未连接设备执行。

## 第一次配置

1. 开启 AppPoint 无障碍服务、悬浮窗权限。升级安装后若截图失败，重新关闭、开启无障碍服务，使新增的截图能力生效。
2. 在 AppPoint 添加并选择游戏，进入应用配置页。Android 11+ 的启动器应用查询已增加 `queries` 声明。
3. 找到“封魔之地自动流程”，点击“应用飓风流预设”或选择自定义，填写轮数、技能名称优先级、截图间隔和超时。名称按高到低用逗号（中英文均可）或换行分隔；同一名称的不同显示方式用 `|` 分隔。按当前三张卡匹配最高优先级项，优先级可直接编辑。默认无匹配时随机一张，可切换为左卡或暂停。
4. 填写三个技能卡中心点击位置、三个 OCR 识别区域及每个界面的识别区域、点击位置、相似度阈值。所有位置使用整个手机截图的归一化坐标：像素 X/截图宽、像素 Y/截图高。例如 1080×2400 截图中的 (540,1200) 是 `0.5,0.5`。
5. 点击“保存封魔流程配置”，然后“显示悬浮窗”，打开游戏。默认区域、点击位置只是占位值，必须按真实画面修改。
6. 手动走完一轮，在每个对应界面使用悬浮窗的“采集目标”循环选择界面，再点“采集当前界面模板”。采集和自动点击时面板会临时隐藏，避免遮挡。
7. 手动配置默认需采集：首页、挑战列表、封魔入口、战斗、选卡、结算。录像预设只使用入口、战斗、选卡、结算四种状态，无需首页及独立挑战模板。失败/次数不足为可选停止模板，目前只支持一张；其他异常通过超时停止。
8. 回到游戏首页、挑战列表、入口、战斗或技能页，点击“开始封魔”。首次从结算页开始不计数、不操作，防止误认上一轮。

## 如何选识别区域

- 选该界面独有的固定标题、图标或边框，避免全屏、怪物、计时器、伤害数字和动态背景。
- 三选一技能页：采集固定的“选择技能”标题/弹窗框架，避开每次随机变化的技能内容。三个 OCR 区域只框对应卡片的完整技能标题，避开描述、等级标记和相邻卡片。
- OCR 在设备本地运行，简体中文模型随 APK 打包。匹配规则是全半角、空白、标点规范化后的精确名称匹配，不做模糊猜测，不理解同义词；显示名称不同请配置别名。
- OCR 读取所框区域的全部文字，因此必须只框技能标题。悬浮窗“只识别技能（不点击）”可展示三个区域的 OCR 文本，用于校准。
- 三张卡名称齐全、连续两帧一致但无优先级匹配：按配置随机选择一张、选择左卡或暂停。任意名称空白则暂停；OCR 名称变化则继续等待，达到战斗超时后停止。OCR 调用自身也有超时。
- 战斗页：采集战斗特有的固定 UI，与技能弹窗页尽量有明显区别。每次技能选择后必须识别到战斗页，才能接受下一次技能弹窗。
- 结算：仅采集胜利画面的固定标志；不要把失败结算当成胜利模板。
- 相似度默认 0.94，使用固定区域缩放到 48×32 后的 RGB 平均误差。不是 OCR，也不搜索全屏目标。它对分辨率比例有一定容忍，但布局、方向、主题变化应重新校准。
- 需要连续两帧识别一致才进行普通操作。两种模板得分差低于 0.025 时视为不确定，不点击；停止模板识别到即停。
- 更改识别区域会删除对应旧模板，必须重新采集。更改配置或模板后必须重新开始流程，不能继续旧流程。

## 运行及异常

- 暂停保留当前步骤、已确认选中的技能和计数；继续从该状态运行。暂停期间请勿手动跳过步骤，已点击过的界面不会自动重复点击。
- “开始封魔 / 重新开始”创建新流程，轮数归零；运行中不会重复启动。
- 计数以“点击胜利结算确定后，识别到封魔入口”为准，不以点击开始或识别结算为准。
- 达到轮数、识别到停止模板、截图/点击失败、等待超时会停止，需要检查后重新开始。
- 游戏离开前台会暂停，不依赖历史无障碍事件包名判断。恢复游戏后可以继续。
- 隐藏/关闭面板会停止运行。面板在截图和点击阶段短暂隐藏，其他时间可暂停；配置页也有暂停按钮。
- 未识别画面只等待，不盲点；普通界面默认 120 秒、每轮战斗默认 600 秒超时。战斗超时不会因弹出技能卡而无限延长。
- 不自动购买次数、复活、观看广告、充值或领取未知弹窗。未配置的异常画面会等待到超时。

配置和模板保存在应用私有目录 `files/demon/<游戏包名>/`，包括 `flow.json` 和按界面命名的 PNG。

## 验证

构建：`./gradlew --no-configuration-cache :app:assembleDebug`

单测：`./gradlew --no-configuration-cache :app:testDebugUnitTest`

单测覆盖：完整流程计数、名称优先级与卡片位置、别名与换行、OCR 稳定性、名称缺失、飓风预设、互斥过滤、选择确认与每轮重置、三系优先顺序、左卡/随机兜底与互斥过滤、单帧抖动、弹窗去重、超时和暂停继续。

真机验收仍需完成：截图权限、悬浮窗隐藏恢复、各模板区分度、随机技能弹窗连续识别、胜利结算回入口、切后台与失败/次数不足的处理。先以一轮配置验证，确认计数及点击正确后再增大轮数。

## 飓风流预设：飓风 → 龙卷风 → 冰霜新星 → 随机

根据用户提供的技能关系图录入名称：飓风术、多重飓风、多重飓风II、飓风增幅、贯通之风、风力回旋、乱流、乱流加剧、风阻、强袭飓风、真空、真空塌陷、风暴聚集。顺序为可编辑示例，不代表最优伤害或当前版本攻略。

- 采用用户指定的整体系别顺序：所有飓风系名称优先于龙卷风系，所有龙卷风系优先于冰霜新星系；三系都没有时随机选一张可选卡片。例如“飓风增幅/龙卷风/冰霜新星”选择飓风增幅，“火球术/强力龙卷/连环霜爆”选择强力龙卷。
- 同系内使用可编辑的示例顺序，不宣称最优。飓风术和龙卷风是不同技能；“风暴聚集”（飓风）和“风暴汇聚”（龙卷风）也分别按精确名称处理。融合前置、等级由游戏控制，本实现选择实际出现的卡片。
- 图中注明选择强袭飓风后不出真空。飓风流会按本局已确认选择过滤这两条冲突分支；还过滤图示“双重龙卷/闪电龙卷”的互斥；截图不能证明现版本的所有规则。
- 只有点击技能后又识别到战斗/结算，才将该技能加入历史；进入下一轮时清空。
- 从战斗中途启动或手动选卡无法还原此前已选技能，互斥历史不完整；建议从封魔入口开始。游戏本身决定技能解锁等级、前置与卡片是否出现，本实现不臆造可用卡片。
- 默认无优先级匹配时随机一张，可能选入其他流派。随机只在三张名称完整、连续两帧一致后触发，并排除本局已知互斥卡；三张都是已知冲突卡时暂停。已有明确保存的左卡/暂停设置保持不变，重新应用飓风流预设会切换为随机兜底。
- 升级旧版配置会保留原有坐标和界面模板；旧位置循环选卡配置不再生效，首次升级后需应用流派并保存。
